# LibrarySearch 1.1.4

兼容多版本 Altium Designer，使用统一 Install.cmd 安装。保存工程、完全退出 AD，完整解压后运行 Install.cmd 并选择 AD。

此正式包基于 1.1.4-rc.7。包含在线搜索分页与缓存、已下载元件总库、库刷新、默认获取 3D 及设置开关、3D Body 专用顶底层对、旧下载总库自动迁移和 PcbLib 格式修复。

更新保留原有下载和设置。已放在 PCB 上的元件需要在 AD 中更新封装才能应用新层定义；Mechanical 1 中的其他图形保留，可按需隐藏。

本次只更新正式产品版本、发行说明及相应共享核心版本信息，Rust 转换器和已有适配器与 rc.7 相同。已验证原生转换器 88 项、各运行时后台回归和安装器隔离检查；不把后台检查视为 AD 实机验收。AD 实际层映射、元件翻面、3D 显示及历史待验收事项仍在验证报告中列明。

正式安装包通过官网与 GitHub Release 提供；以发布页面中的附件及校验值为准。
