# 1.1.4-rc.6 · 默认获取 3D

在线获取元件默认同时尝试获取并嵌入 3D 模型。可在“设置 → 库目录 → 在线获取”取消“获取元件时同时获取 3D 模型”；离开设置时保存，重启后保持选择。

新用户及尚未包含此选项的旧设置默认开启。取消后不主动联网下载 STEP，优先获取符号和封装；已经缓存或嵌入的 3D 不删除。仍可通过元件详情中的“获取 3D”单独补齐。后续更改外观、目录和本地库扫描会保留这一选择。

普通获取使用统一的完成提示，不因没有可用 3D 额外弹出提醒。已知源库没有 3D 时，重复获取可复用现有符号和封装，不反复生成相同无模型版本。单独点击获取 3D 时仍显示该次操作的结果。

保留 rc.5 的总库刷新及 rc.4 的 PcbLib 格式修复。自动检查不替代实际 AD 连续放置、ECO、保存重开和 PCB 3D 预览验收。
