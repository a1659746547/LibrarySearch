# 已下载元件总库 · 1.1.4-rc.3

“已下载”中的所有元件自动汇总到保存目录下的 `Unified/LibrarySearch.SchLib` 与 `Unified/LibrarySearch.PcbLib`。这是同一个配套总库的符号文件和封装文件。已有下载在打开面板时自动汇总；新增、重新获取、补齐 3D 和批量删除缓存后自动更新。无需逐个导入。

选择已下载元件点击“查看库”，打开对应的总符号库或总封装库，不再逐个打开编号文件。查看总库后请关闭该库文档，再继续新增或更新元件，避免 AD 文件锁阻止更新。

放置在线元件时，工程统一使用 `Libraries/LibrarySearch/Unified/LibrarySearch.SchLib` 和 `LibrarySearch.PcbLib`，后续放置复用这两个固定路径。工程副本包含当前已下载元件，并保留该工程此前使用的旧元件和旧 3D 版本。复制工程时请一并保留 Libraries 目录。

同一型号的不同 C 编号、不同下载修订使用不同内部标识，避免同名覆盖和符号关联到错误封装。列表仍显示原始型号、简介及封装名。STEP 资源随 PcbLib 合并，保留原来的模型位置和旋转；没有 3D 的元件不会凭空生成模型。

每个编号的原始下载缓存仍在 Components 中保留，供校验、查看来源、重新构建和删除使用。AD 新增的工程引用使用总库，不再为每个新元件增加一对文件。升级前已加入工程的分散库引用保留，避免破坏旧元件；确认旧工程不再需要后可自行移除旧引用。

删除下载缓存会更新全局总库，不删除工程副本。总库存在外部编辑或被锁定时会停止替换并保留原文件；请先保存、关闭 AD 中打开的总库，再重试。更新使用成对文件的回滚记录，中断后会恢复此前完整版本。请勿手工编辑插件管理的总库；需自定义的元件请另存到用户库。

## 验证边界

离线测试覆盖同名元件、字体、引脚可见状态、嵌入 STEP、缓存增删、固定工程路径、旧工程元件保留、文件锁、外部编辑与中断恢复。多版本适配器与共享核心进行接口和安装校验。实际 AD 中连续放置、ECO、保存重开及 3D 显示仍需实机验收。本候选没有宣称解决 rc.1 遗留的模型偏移和 WorkspaceManager 闪退。
