# LibrarySearch 1.1.4-rc.1 验证说明

## 修复内容

获取 3D 前后的封装原来使用相同名称。新旧库同时保留在工程时，符号只按封装名称查找，可能仍解析到旧的无 3D 版本。

本版为每次生成的库分配唯一封装标识，并将符号的 PCB 模型链接指向同一标识。旧工程与旧库文件不覆盖。旧缓存首次使用时重新生成，新旧版本可以并存。

保留 1.1.3 的 JSON 兼容性修复，避免 AD25 部分运行环境无法加载 System.Web.Extensions。

## C15127 验证步骤

1. 保存工程并退出 AD，完整解压本安装包，运行 Install.cmd。
2. 新建独立测试工程、原理图和 PCB，先保存所有文件。
3. 搜索 C15127，点击“获取 3D”，等待显示“含 3D”。
4. 从插件重新放置符号，标注位号后执行更新 PCB。
5. 在 PCB 切换 3D，检查元件实体、焊盘对应、方向和高度。

旧原理图中的符号和旧 PCB 元件不会自动改写。仅重新安装插件不会给已有 PCB 元件补上模型。请先在测试工程验证；已有工程需要重新指定新版封装并执行库更新。

## 已验证和待验证

- C15127 本机第一次获取的库无 STEP；第二次“获取 3D”后的库有一个完整 STEP，解压后 2,774,707 字节，模型表与实体关联一致。
- 自动化测试覆盖：先生成无 3D 库，再生成含 3D 库；新符号链接新版封装；旧库字节保持不变；长标识经过 SchLib/PcbLib 写入与读回保持一致。
- C7473159 曾在本机 AD24.0.1 的独立库及独立 PCB 上显示 3D，但观察到模型偏移。本版不宣称修复所有模型的方向、位置或源数据几何。
- C15127 的新版 AD 实机显示和符号到 PCB 的完整更新流程仍待验收，本版作为验证版本提供。
- 2026-11-07 18:06 的 AD24 闪退事件指向 WorkspaceManager.DLL，异常 0xc0000005。尚无证据证明本版能修复该崩溃。

本版未自动安装、部署网站或发布更新。
